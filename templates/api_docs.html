📝 Text API Endpoints

POST /api/text/uppercase

Convert text to uppercase

{"text": "hello"} → {"result": "HELLO"}
POST /api/text/lowercase

Convert text to lowercase

{"text": "HELLO"} → {"result": "hello"}
POST /api/text/reverse

Reverse the text

{"text": "hello"} → {"result": "olleh"}
POST /api/text/length

Get text length

{"text": "hello"} → {"result": 5}
POST /api/text/word-count

Count words in text

{"text": "hello world"} → {"result": 2}

📦 Batch Processing API NEW

Process multiple text operations in a single request for improved efficiency.

POST /api/batch

Process multiple operations at once (max 100 operations per request)

Request Format

{ "operations": [ {"operation": "uppercase", "text": "hello"}, {"operation": "reverse", "text": "world"}, {"operation": "length", "text": "test"} ] }

Response Format

{ "success": true, "results": [ {"success": true, "result": "HELLO", "operation": "uppercase"}, {"success": true, "result": "dlrow", "operation": "reverse"}, {"success": true, "result": 4, "operation": "length"} ], "processed": 3, "failed": 0, "total": 3, "elapsed_ms": 5.234 }

💡 Code Examples

cURL

# Single operation curl {{ site_config.SITE_URL }}/api/text/uppercase \ -X POST \ -H "Content-Type: application/json" \ -d '{"text": "hello world"}' # Batch operation curl {{ site_config.SITE_URL }}/api/batch \ -X POST \ -H "Content-Type: application/json" \ -d '{ "operations": [ {"operation": "uppercase", "text": "hello"}, {"operation": "reverse", "text": "world"} ] }'

Python

import requests # Single operation response = requests.post( "{{ site_config.SITE_URL }}/api/text/uppercase", json={"text": "hello world"} ) print(response.json()) # Batch operation response = requests.post( "{{ site_config.SITE_URL }}/api/batch", json={ "operations": [ {"operation": "uppercase", "text": "hello"}, {"operation": "reverse", "text": "world"} ] } ) print(response.json())

JavaScript (fetch)

// Single operation fetch('{{ site_config.SITE_URL }}/api/text/uppercase', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({text: 'hello world'}) }) .then(r => r.json()) .then(data => console.log(data)); // Batch operation fetch('{{ site_config.SITE_URL }}/api/batch', { method: 'POST', headers: {'Content-Type': 'application/json'}, body: JSON.stringify({ operations: [ {operation: 'uppercase', text: 'hello'}, {operation: 'reverse', text: 'world'} ] }) }) .then(r => r.json()) .then(data => console.log(data));
